# Cinema Booking Application 🎥🍿

This is a React-based web application that allows users to view current films playing in cinemas and book seats for their favorite movies. The application is designed to provide a seamless experience for movie enthusiasts to browse films and reserve their seats.

## Features
- **Now Playing Films:** Display a list of films currently playing in cinemas.
- **Film Details:** Click on a film to view its details and enter the booking room.
- **Seat Booking:** Select and book your seats directly on the film's room page.
- **Persistent Seat Selection:** Your selected seats are saved locally, so you can revisit the page without losing your selection.

## View the Application

## How to Use
1. Browse the list of now-playing films on the home page.
2. Click on the "Find Seat" button for a specific film to enter the booking room.
3. Select your desired seats by clicking on them.
4. Leave the page and come back later—your seat selections will remain saved!

## Technologies Used
- React
- React Router
- Local Storage (for persistent seat bookings)
- TMDB API (for fetching film data)

## Deployment
The application is hosted using GitHub Pages. Updates to the application are automatically reflected upon successful deployment.
